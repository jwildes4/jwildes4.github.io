### [CIS 641 F2026 Project - Team WildData](https://jwildes4.github.io/GVSU-CIS641-WildData/)

## CIS 641 F2026 Project Description

This semester, I am working on a project called ExcelFlow, which is a data management system designed to make transferring information from Excel spreadsheets into a PostgreSQL database easier and more reliable. The project addresses a common business problem of manually moving spreadsheet data into a database can take considerable time and introduce errors. This ExcelFlow system aims to simplify this process by allowing users to upload Excel files, map spreadsheet columns to database fields, and validate their data before importing it.

Throughout the project, I will focus on defining the system's requirements, planning its functionality, and identifying the technologies and design decisions needed to develop a practical solution. The planned features include identifying invalid or missing data, generating reports that explain validation errors, and restricting database imports to authorized users. I also will look to establish performance and usability requirements to ensure the system can process spreadsheets efficiently and present results in a format that users can understand.

This project will allow me to apply software engineering and information systems concepts to a realistic business problem. By organizing requirements by feature, considering security and performance, and planning the development and testing process, I will gain experience in approaching software development systematically rather than focusing only on writing code. The intended outcome is a functional tool that reduces manual effort, improves data quality, and makes spreadsheet-to-database transfers more efficient for organizations.
